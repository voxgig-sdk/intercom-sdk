Authentication: bearer token (bearerAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | Intercom-Version | header | enum: 1.0, 1.1, 1.2, 1.3, 1.4, 2.0, ... | No | |

Request body

application/json

Property Type Required Description
action enum: publish, unpublish, delete, set_availability, set_audience, update_tags Yes The bulk action to perform. Allowed content_ids[].type values vary per action: * publish, unpublish: article_content * delete: article_content, content_snippet, file_source_content, internal_article * set_availability, set_audience: article_content, content_snippet, external_content, file_source_content, internal_article * update_tags: article (the parent Article id, not article_content), content_snippet, external_content, file_source_content, internal_article
audience object No Required when action is set_audience. Manages segment membership.
audience.add_segment_ids array of integer No Segment IDs to assign to the selected content.
audience.remove_all boolean No When true, removes all segments from the selected content.
audience.remove_segment_ids array of integer No Segment IDs to remove from the selected content.
availability object No Required when action is set_availability. Each field is optional, only the properties present in the request are toggled.
availability.ai_agent boolean No Toggle Fin AI Agent availability.
availability.copilot boolean No Toggle Copilot availability.
availability.sales_agent boolean No Toggle Sales Agent availability.
content_ids array of object Yes Up to 1,000 content items to apply the action to.
content_ids[].id string Yes
content_ids[].type enum: article, article_content, content_snippet, external_content, file_source_content, internal_article Yes
tags object No Required when action is update_tags. Applies and/or removes existing tags. Supply at least one of add_tag_ids / remove_tag_ids. At most 100 distinct tag IDs may be supplied across add_tag_ids and remove_tag_ids combined. Tag IDs must reference existing, non-archived tags; exceeding the limit or referencing unknown or archived IDs is rejected with parameter_invalid (HTTP 422).
tags.add_tag_ids array of integer No Tag IDs to apply to the selected content.
tags.remove_tag_ids array of integer No Tag IDs to remove from the selected content.
