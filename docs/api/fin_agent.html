POST /fin/csat

Operation ID: submitFinCsat.

Authentication: bearer token (bearerAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | Intercom-Version | header | enum: 1.0, 1.1, 1.2, 1.3, 1.4, 2.0, ... | No | |

Request body

application/json

Property Type Required Description
conversation_id string Yes Your external conversation ID, the same ID you started the conversation with, and the one echoed on the csat_requested event.
rating enum: terrible, bad, ok, good, amazing Yes The rating the user selected, one of the key values from the csat_requested event's options.
remark string No Optional free-text comment the user left alongside the rating. Can be added to an already-rated survey, but only once, the rating locks after a remark is recorded.

Responses

200: Rating recorded successfully

application/json

Property Type Required Description
conversation_id string No The external ID of the rated conversation.
rating enum: terrible, bad, ok, good, amazing No The rating now recorded on the conversation.
status enum: rated No The result of the submission.
401: Unauthorized

application/json

Property Type Required Description
errors array of object Yes An array of one or more error objects
errors[].code string Yes A string indicating the kind of error, used to further qualify the HTTP response code
errors[].field string No Optional. Used to identify a particular field or query parameter that was in error.
errors[].message string No Optional. Human readable description of the error.
request_id string (uuid) No
type string Yes The type is error.list
422: The rating could not be recorded. Common causes: no conversation exists for the given conversation_id, Fin never requested a rating for it, the rating window has closed, the rating is locked because a remark was already submitted, or rating is not one of the supported values.

POST /fin/reply

Operation ID: replyToFin.

Authentication: bearer token (bearerAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | Intercom-Version | header | enum: 1.0, 1.1, 1.2, 1.3, 1.4, 2.0, ... | No | |

Request body

application/json

Property Type Required Description
attachments array of object No An array of attachments to include with the message. Maximum of 10 attachments.
attachments[].content_type string No The MIME type of the file. Required when type is 'file'.
attachments[].data string (byte) No Base64-encoded file data. Required when type is 'file'.
attachments[].name string No The name of the file. Required when type is 'file'.
attachments[].type enum: url, file Yes The type of attachment.
attachments[].url string (uri) No The URL of the attachment. Required when type is 'url'. Must be publicly accessible.
conversation_id string Yes The ID of the conversation.
message object Yes A message exchanged within a Fin Agent conversation.
message.author enum: user, agent, fin Yes The author that created the message.
message.body string Yes The body of the message. Accepts both plain text and HTML format. When sending a message to Fin, this should contain the user's message. Fin's response will be returned as HTML.
message.timestamp string (date-time) Yes The timestamp when the message was created. Used to deduplicate messages sent within a 5 minute window. Ideally should include milliseconds for higher precision.
message.timestamp_ms string (date-time) No The timestamp when the message was created, with millisecond precision. Only present in webhook event responses (fin_replied).
user object Yes A user object representing the user in a Fin Agent conversation.
user.attributes object No A hash of attributes associated with the user. Attributes can be used by Fin to target content and responses. Limit to 10 attributes.
user.email string (email) No The email of the user.
user.id string Yes The ID of the user. This value will be used to uniquely identify the user during a conversation with Fin. Maps to the user_id field on the Intercom User object.
user.name string No The name of the user.

200: Reply sent successfully

application/json

Property Type Required Description
conversation_id string No The ID of the conversation.
created_at_ms string (date-time) No The timestamp the response was created at, with millisecond precision.
errors object No Contains error details if any user or conversation attribute updates failed.
errors.conversation object No Conversation-related attribute errors.
errors.conversation.attributes object No Map of conversation attribute names to error messages.
errors.user object No User-related attribute errors.
errors.user.attributes object No Map of user attribute names to error messages.
sse_subscription_url string No Optional. A URL to subscribe to Server-Sent Events (SSE) for this conversation, if SSE is enabled. The access token is a JWT with a 3-minute TTL. The token is revoked when Fin sets the conversation to awaiting_user_reply or complete status. When CSAT is enabled and a survey will follow the resolution, complete revocation is deferred until the csat_requested event is delivered or the token expires.
status enum: thinking, replying, awaiting_user_reply, escalated, resolved, complete No Fin's current status in the conversation workflow.
user_id string No The ID of the user.
