POST /fin_voice/register

Operation ID: registerFinVoiceCall.

Authentication: bearer token (bearerAuth).

Request body

application/json

Property Type Required Description
call_id string Yes External call identifier from the call provider
data object No Additional metadata about the call
phone_number string Yes Phone number in E.164 format for the call
source enum: five9, zoom_phone, aws_connect No Source of the call. Can be "five9", "zoom_phone", or defaults to "aws_connect"

Responses

200: successful
